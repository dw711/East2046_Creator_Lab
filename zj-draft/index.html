          Reusable workflow

          1. Read the brief; list the claims and the three questions to answer.
          2. Put every word, number, link and credit in src/data.js.
          3. Fact-check each claim against its source (table above).
          4. Generate the 3D world with MANI from a written prompt; test the embed.
          5. Build, then test: phone, keyboard, reduced motion, 3D skipped.
          6. Run build.py to produce one self-contained file.
